# مختبر الألوان — تعلّم باللعب

لعبة تعليمية عربية تفاعلية تحاكي مختبراً افتراضياً لاستكشاف مزج الألوان وبعض المفاهيم العلمية البسيطة.

## التشغيل
افتح `index.html` مباشرة في المتصفح؛ لا تحتاج اللعبة إلى تثبيت أو اتصال بالإنترنت.

## مميزات اللعبة
- واجهة عربية من اليمين إلى اليسار ومتجاوبة مع الهاتف والحاسوب.
- تحديات متتابعة، نقاط، ودفتر لتسجيل التجارب.
- عينات افتراضية ونتائج مرئية داخل كأس المختبر.
- لا تستخدم مكتبات أو ملفات خارجية.

> **تنبيه:** هذه محاكاة تعليمية خيالية. لا تخلط مواداً حقيقية؛ نتائج اللعبة ليست تعليمات لتجارب كيميائية فعلية.
